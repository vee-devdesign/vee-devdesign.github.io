Procedural Basic Grass

Procedural distribution of blades of grass across a surface using an Instance on Points pipeline. Configured random variations in scale, tilt, and custom rotation vectors to achieve a photorealistic organic appearance.

Node Logic
BLENDER GEOMETRY NODES SCHEMA

The wind effect is created in the Shader Editor using a `Noise Texture`,
which is moved along one of the axes using a `Value` node (via `#frame`)
and shifts the coordinates and normals of the blades of grass.

Distribution Options
DISTRIBUTION & FIELD POSSIBILITIES

This is the “lightest” wind. It “works instantly in Viewport“,
doesn't require physics baking, and is ideal for huge fields (backgrounds).
